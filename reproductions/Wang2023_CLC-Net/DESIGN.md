# CLC-Net 复现设计

Wang 等，Neurocomputing 527 (2023) 100–109。doi:10.1016/j.neucom.2023.01.013。

文献编号 M-CLC-2023。PDF 在 `literature/batch2/03_fundus_methods/Wang2023_CLC-Net.pdf`。没有作者代码，也没有公开权重。这里的结构、损失和超参数按论文第 3 节、第 4.1 节和图 2、图 3 实现。论文没写的量写在下面的假设里，并固定在 `clcnet/assumptions.py`。这些假设不拿原文表格里的 AUPR 来回改。

原文表格只放在 `paper_reported.tsv`，来源列是「原文汇报」，用来事后对照。

## 论文已经写明的部分

两条分支结构相同、参数不共享。编码器是 SE-ResNeXt-50。局部分支输入从原图裁出的 256×256。上下文分支输入是以该窗口为中心的 512×512。图 2(b) 在上下文编码器前画了 2 倍下采样，正文也写上下文输入被降到更低分辨率。因此 512 的图先双线性变成 256，再进编码器。

解码块的名字是 Conv2d-BN-SKNet-TransConv2d。空间尺寸加倍，通道数减半。块内的 SKNet 使用 3×3、5×5、7×7。编码器特征与对应解码层拼接。四个解码尺度在图 2(a) 上标成 1/16、1/8、1/4、1/2。

深监督按第 3.1 节的具体做法：每个中间层上采样到监督掩膜的大小，拼接，再映射成最终分割。图 2 的图例把向下的箭头写成 Bilinear Downsampling，正文写的是 bilinear upsampling。实现跟随正文。

两条分支的编码器底部各有一个分类头，两层全连接，监督是补丁里出现的病灶类型，4 维 0/1 向量，用二元交叉熵。第 3.2 节的例子是 1110 表示有 MA、EX、HE，没有 SE。

分割损失是 Dice 与加权多类交叉熵之和。Dice 对病灶类求和，不含背景。权重是背景、HE、MA、EX、SE 对应 1、2、2、2、2。分类损失是标准二元交叉熵。

训练：batch 16，Adam，初始学习率 3e-4，第 20 轮和第 50 轮各乘 0.1，共 60 轮。PyTorch。推理仍走图 2(b) 的协作结构，分割结果取局部分支。

预处理：Otsu 去掉非组织区域；256 窗口、相邻窗口重叠 128；实时做水平翻转、垂直翻转、旋转、平移、缩放和裁剪。

数据：IDRiD 用挑战赛官方训练/测试划分，图像 4288×2848，共 81 张。DDR 按 L-Seg 的官方划分，383 / 149 / 225。e-ophtha 只保留同时有 MA 和 EX 的 21 张，随机 15 张训练、6 张测试。指标是精确率-召回率曲线下面积，与 IDRiD 挑战赛一致。e-ophtha 的均值只对 MA 和 EX。

额外输入：没有。只有 RGB 眼底图像。结果文件里写 `extra_inputs: []`。

论文给出的模型规模是 92.19 M 参数、20.58×10^9 FLOPs。这是事后对照，不是调参目标。

## 固定假设

A1. 编码器按图 3 做成 SE-ResNeXt-50，32 路、每路 4 通道，层数 [3, 4, 6, 3]，SE 缩减比 16。不加载 ImageNet 权重，因为论文没有写预训练。卷积用 Kaiming fan_out 初始化。BatchNorm 用 PyTorch 默认 momentum 0.1、eps 1e-5。

A2. 名为 Conv2d 的那一层论文没写核大小。这里用 1×1，并把通道数减半，后面接 BN 和 ReLU。SKConv 保持该通道数。TransConv2d 用核 2、stride 2、带偏置，只把空间尺寸加倍。若在 2048 通道上先做 3×3 再做 2×2 转置卷积，单层参数就会超过论文报告的整个模型，所以不采用那种读法。选定之后不再为了贴近 92.19 M 去改宽度。

A3. 5×5 和 7×7 按被引用的 SKNet 实现成膨胀率 2 和 3 的 3×3 分组卷积。分组数 G=32，缩减比 r=16，瓶颈下限 L=32。每个分支是分组卷积、BN、ReLU。融合是全局平均池化、1×1、BN、ReLU，再对三个分支做 softmax。

A4. 跳跃连接用四个尺度：layer3（1024 通道，1/16）、layer2（512，1/8）、layer1（256，1/4）、stem 卷积输出（64，1/2）。解码停在 1/2，不再做第五次转置卷积。最终分辨率靠 A5 的双线性上采样补到 256。

A5. 每个解码特征先用 1×1 变成 5 类，再双线性上采样到 256，四张图在通道维拼接，最后用 1×1 得到分割 logits。分割损失只加在这张最终图上。1×1 投影是为了让中间输出在 batch 16、24 GB 的设定下是类别图，而不是把上千通道的特征图放大到全分辨率。

A6. 上下文图像从 512 双线性缩到 256，`align_corners=False`。上下文分割标签对每个类别做 2×2 最大池化，再按 A9 的优先级合成一张单标签图。这样 1 个像素宽的病灶不会在最近邻下采样里整块消失。

A7. 融合加在跳跃拼接之后的四个解码特征上。SKM 只处理上下文特征；输出与局部特征拼接，再用 1×1、BN、ReLU 压回原来的通道数，后面的解码块才能保持和单分支相同的通道表。`loc+cont` 消融不做 SKM，仍保留这次投影。两条分支的特征图已经同为 256 输入上的对应尺度，不再做中心裁剪。

A8. 分类头是全局平均池化，全连接 2048→512，ReLU，全连接 512→4。标签顺序采用第 3.2 节：MA、EX、HE、SE。引言里的 0110 例子与这一节冲突，不采用。某个病灶在补丁里有任一正像素就记 1，重叠类型可以同时为 1。标签在增强之后计算。

A9. 分割类别顺序与权重句子一致：0 背景、1 HE、2 MA、3 EX、4 SE。一个像素落在多张掩膜上时，优先级是 MA、HE、EX、SE。分类头仍按 A8 保留多标签，两套顺序都写在代码常量里。

A10. Dice 的 ε 取 1，加在分子和分母。四个病灶类的 Dice 损失相加，在整个 mini-batch 的全部像素上计算，不含背景。wMCE 是每个像素的加权负对数似然，再对像素取平均。存在的分支把分割损失和分类损失直接相加，系数都是 1。

A11. Adam 的 β1=0.9，β2=0.999，ε=1e-8，weight decay=0。学习率从该轮开始生效：第 1–19 轮 3e-4，第 20–49 轮 3e-5，第 50–60 轮 3e-6。不提前停止。DDR 的验证集只在单独调用评估时使用，不参与选模型。对外检查点是第 60 轮。

A12. 增强先作用在 512 的上下文图像和四张病灶平面上，再取中心 256 作为局部样本，因此增强之后局部窗口仍是上下文窗口的中心。水平翻转概率 0.5，垂直翻转概率 0.5，旋转角在 [0, 360) 度上均匀，平移在边长的 ±10% 内均匀，缩放在 [0.8, 1.2] 上均匀。仿射的输出尺寸保持 512，这就是论文里的 cropping。图像填充 0，掩膜填充背景。

A13. Otsu 用亮度 Y=0.299R+0.587G+0.114B，不另做模糊。若图像边缘上多数像素被判成前景，则反相。取最大连通域并填洞，裁到外接矩形。矩形内、视野外的图像像素置 0。标注不被视野掩膜擦掉。局部窗口 256、步长 128；边长不能被步长整除时，再补一个贴着边界的窗口。上下文窗口是 512，中心与局部窗口重合，越界补 0。局部窗口里没有视野像素就丢掉。

A14. 像素除以 255，映射到 [0, 1]。不做数据集均值或方差归一化。

A15. 推理对局部分支的 softmax 概率按重叠区域平均。主结果用这个局部分支。评估上下文头时，先在 256 上做 softmax，再双线性放大到 512，按上下文窗口拼回去。任何窗口都没覆盖到的像素，背景概率设为 1，病灶概率设为 0。

A16. AUPR 把该划分里该病灶的全部像素放在一起计算，是精确率-召回率曲线下面积。分数相同的像素用稳定排序。没有正样本的类别记为 NaN，不进均值。Dice 和 IoU 是辅指标，预测取 argmax，对照的是原始二值掩膜，不是互斥之后的训练标签，再对图像取平均。e-ophtha 只计算 MA 和 EX。

A17. e-ophtha 先找同时出现在 MA 子集和 EX 子集、且不在 healthy 目录里的图像，数量必须是 21。文件名排序后，用 NumPy `Generator(PCG64(20230108)).permutation`，前 15 个训练，后 6 个测试。第一次生成的名单写入 `splits/eophtha_seed20230108.json`，之后只读这个文件。IDRiD 用目录中的训练/测试划分。DDR 用官方 train / valid / test 目录，期望数量 383 / 149 / 225。数据根目录若有 `manifest.csv`（列 id,split,image,HE,MA,EX,SE），以清单为准。

A18. 种子 20230108 同时设置 Python `random`、NumPy、PyTorch 和 cuDNN 的 deterministic 标志。每个训练样本的增强随机数是 `SeedSequence([20230108, 轮次, 样本下标])`，与 DataLoader 的 worker 顺序无关。

A19. 补零区域参与损失，标签是背景。

A20. 训练 DataLoader 丢掉最后不足 16 的批次，使每次 Adam 更新都看到论文写的 batch 大小。评估批大小默认 4，只影响显存，不写入科学设定。

A21. 额外输入没有。不拼接血管、视盘或文本。

A22. 每轮覆盖 `last.pt`。另外保存第 20、50、60 轮。报告用第 60 轮。

## 消融开关

`clcnet/assumptions.py` 里的 variant 对应表 1 的训练设定：

| 名称 | 分支 | 融合 | 分类头 |
| --- | --- | --- | --- |
| loc | 局部 | 无 | 无 |
| loc_cl | 局部 | 无 | 有 |
| cont | 上下文 | 无 | 无 |
| cont_cl | 上下文 | 无 | 有 |

## 实现后的规模

结构按上面的假设定死之后，用 `tools/complexity.py` 统计一次。统计值写在这里，只和论文的 92.19 M、20.58×10^9 对照，不回头改通道。

在 CPU 上对 `full` 做了一次前向和反向，batch 为 2。局部分支 logits 是 2×5×256×256，上下文分支 logits 同样是 2×5×256×256，两个分类头都是 2×4。

参数量 119,700,842（119.70 M）。一次前向（一张 256 的局部图加一张 512 的上下文图）的乘加数是 1.247×10^11；若把一次乘加计成两次浮点运算，则是 2.494×10^11。论文写的是 92.19 M 和 20.58×10^9。两边都对不上。差主要来自解码器和融合层仍使用 ResNeXt 的通道数，论文没有给出另一套通道表。这里不再改宽度去贴近这两个数。
