一、范围与决定
  实现的是 15 第四、五、六节在 16 第三节 E5a、E5b 两行范围下的推理档：
    a 零样本：SAM ViT-H 和 SAM 2.1 Hiera-L 的自动掩码（登记网格里选一组），SAM 3 文本提示（每类三条措辞，验证池上选一条）。
    b 理想提示：SAM ViT-B 只做框，SAM 2.1 点和框，MedSAM 框；k ∈ {1, 5, 20, 全部}；同信息对照（M2MRF、nnU-Net 的概率图限制到同样的框）。
  2026-10-12 步骤 0 定下的九项（D1–D9，依据在 00 同日记录；用户决定 D1 按 16、其余按建议）：
    D1 a 档参数：网格 点密度 {64, 128} × 面积上限 {0.5%, 2%, 不限}（上限按画布视野面积比例），在验证池上按 AUPR_any_lesion 选一组，测试集只跑选中的；原来 15 写的"两套作者参数、不调"和"训练集最大连通域上限"作废。预算规则：128 当选则 TJDR_uwf 只跑 fov 变体（建议，可否决）。
    D2 验证池 = IDRiD 验证 10 张 + DDR 验证 149 张；a 档网格、SAM 3 措辞、推理档 Dice 阈值都只在池上选。
    D3 b 档 SAM 用 ViT-B（a 档仍 ViT-H）。  D4 k 四档。  D5 点提示只做 SAM 2.1。
    D6 k = 全部跑七个测试集，k 曲线只在 IDRiD、DDR；同信息对照保留。
    D7 TJDR_uwf 在 G1 下按 45° 取 4256 长边，另报 fov 变体 1440。
    D8 零样本的任意病灶图写进四个类目录，bench.eval 的 AUPR_any_lesion 就是它的合并 AUPR。
    D9 点框提示的文件叫 prompted.py。

二、协议文件 bench/configs/e5_frozen.yaml（推理档相关的节）
  validation_pool：IDRiD、DDR 的 val 划分；thresholds 一句说明阈值取合并直方图的每类 Dice 最优。
  geometry.G1：窗口 {SAM: 1024, SAM 2: 1024, MedSAM: 1024, SAM 3: 1008}，overlap 0.5；TJDR_uwf: {long_side: 4256, comparison_variant: {fov: 1440}}。G2：整个视野裁剪交给模型自己缩放。
  zero_shot.grid：points_per_side、area_cap_fraction、select_on、select_by、selected（空，池上选完填）、budget_rule。
  zero_shot.sam / sam2：checkpoint、generator_defaults（库默认，代码不写数字）。
  zero_shot.sam3：checkpoint、confidence_threshold 0、pixel_score、phrases（每类三条）、select_on、selected（空）。
  zero_shot.outputs：main any_lesion、upper_bound oracle_class、sensitivity area_cap。
  oracle：models、checkpoints、components、k、curve_sets、order、box、point、decode、medsam、same_information_reference。
  时限：文件头规定读到第一个 E5 测试指标后不再改；两个 selected 只从验证池写，写完提交再跑测试集。bench/e5/frozen.py 的 validate() 在缺节缺键时报错，assert_ready() 在测试划分前检查两个 selected 和提示文件。

三、模块（bench/e5/，每个文件头有完整说明）
  frozen.py      读协议并校验；pool_sets、grid_pairs（六组）、selected_pair、phrase_ids、selected_phrases、k_levels、oracle_models、prompt_file、assert_ready。
  geometry.py    七个测试集的名字和目录（读 e3a_frozen.yaml）；long_side_for（标准视野 1440，TJDR_uwf 4256 / fov 1440）；window_size、windows（复用 bench.infer.window_starts，最后一窗贴边）；crop_window（画布比窗口小时右下补零，每窗同尺寸同点密度）；plan（G1 窗口 / G2 整图）；canvas（走 bench.data.b1_input.crop_resize，保持 uint8，可带四类画布真值）；paste（双线性回贴视野框，视野外 0）。
  prompts.py     b 档提示文件 runs/E5_prompts/<集>_<划分>[__变体].json：八连通域；按首像素行主序排序后用 SeedSequence(20261003, spawn_key=sha256(图/类)) 派生的 PCG64 做一次置换并记 rank；紧框 [x0, y0, x1, y1]（右下不含）；点取 EDT 最远像素、并列取行主序第一个；记每图画布尺寸、每类掩码文件 sha256、每图每类连通域数。所有模型读同一份。
  score_rules.py Mask 记录（窗口坐标掩码 + 偏移 + predicted_iou + stability_score，from_record 直接吃 SAM / SAM 2 生成器的字典）；combine_max 跨窗口按偏移取逐像素最大并裁掉越出画布的部分；masks_to_score（IoU 最大值，裁到 [0, 1]）；as_four（D8）；oracle_class（分给重叠最多的类，并列按 MA、HE、EX、SE 第一个，无重叠计入四类）；area_cap（比例 × 画布视野像素，面积只数画布内）。
  outputs.py     runs/E5/<档>/<来源>/<集>[__变体]/{prob_test|prob_val, predicted.json, metrics.json, metrics.npz, done.json}；来源名 <档>_<模型 slug>_<token>...（a_sam_vith_p64、a_sam2_hieral21_p128、a_sam3_ph0、a_sam3_selected、b_sam_vitb_box、b_sam2_hieral21_point、b_medsam_vitb_box、b_m2mrf_ref_ddr_seed0）；变体 token 允许单下划线、双下划线分隔；池运行在 <集>-val 下用 prob_val；checkpoint_record 记权重 sha256；pool_thresholds / pool_class_aupr 合并两个池运行的像素直方图；evaluate_dir 调 bench.eval.evaluate 写三份结果，drop_maps 只删测试划分的图；needs_prediction 让 --limit 冒烟目录在之后被重做；is_done(目录, limit) 带冒烟语义：全量请求不认 --limit 写的 done.json，write_predicted 重写预测时删旧的 done / metrics，池直方图忽略 limit 运行（2026-10-12 评审修复 2）；thresholds_for_test 在测试划分拿不到池阈值时抛 RuntimeError 而不是退成 fixed only（预测为冒烟时例外），evaluation_scope 让评测范围与阈值例外都跟随目录里 predicted.json 的 limit 而不是本次请求（2026-10-12 评审修复 3）；drop_maps_of 删图并在 done.json 记 maps_dropped（评审修复 4）。
  amg.py         SAM / SAM 2.1 自动掩码。generator_params 只有密度加库默认；build_generator 走 bench.models.foundation.official 导入；池运行每档面积上限 × {任意病灶, oracle_class, stability} 九个目录，测试运行只跑选中的一组三个目录（上限记在 predicted.json，不进目录名）；预算规则 budget_rule_skips；每窗耗时写进 predicted.json；测试运行的阈值取池里同上限同种类的目录。
  prompted.py    b 档点框提示。每个提示在"框中心离窗口边缘最远"的窗口里解码，每窗一次 set_image；k 图按 rank < k 一遍填成前缀最大值（不存逐提示的图）；SamDecoder 同时适配 segment_anything 和 sam2 的 ImagePredictor（点取 IoU 最高、框取单掩码、logits 过 sigmoid）；MedSamDecoder 照 MedSAM_Inference.py（1024 输入逐图最小最大归一、框、256 输出 sigmoid 后双线性，只接受框）；拒绝集 / 划分 / 变体 / 画布尺寸不符的提示文件。
  same_info.py   同信息对照：监督模型的原分辨率概率图乘以前 k 个框并集（框从画布外扩取整映射回原图），来源 b_<模型>_ref_<tokens>，只用固定阈值评测。
  sam3_text.py   一个运行 = 一个措辞序号覆盖四类（a_sam3_ph0/1/2）；Sam3Scorer 只收 PIL 图，像素分数 = 查询分数 × 掩码概率的最大值；build_scorer 以 load_from_HF=False 读 pretrained/sam3.pt，置信阈值 0，分辨率 1008；select_phrases 按池合并直方图的每类 AUPR 选措辞并打印可粘进 e5_frozen 的 yaml；assemble_selected 逐类复制选中序号的图拼出 a_sam3_selected（不另推理），run 在三个序号齐且 selected 已填时自动拼装；2026-10-12 评审修复 4：拼装项是 a_sam3_selected 的唯一写者，措辞运行不删自己的图（--drop-maps 对它无效），队列里的措辞项带 --no-assemble；assemble_selected 缺措辞运行或图丢失时抛错（run 里 missing_ok 返回 None），复制经 prob_*.partial 暂存后 rename，评测前 ensure_pool_selected 补拼池上的 a_sam3_selected，评测完且集合在 drop_maps 里才用 outputs.drop_maps_of 删三个措辞目录和自己的图；全量请求拒绝冒烟的措辞运行。
  四个模块各有 planned()（启动器和运行用同一套目录计算）。

四、输出与记录
  predicted.json（预测完成）：tier、model、source、set、split、variant、variants、geometry、canvas_long_side、window、overlap、n_images、limit、耗时（每窗 / 每提示均值）、checkpoint（文件名、sha256、字节）、host / gpu / torch / git；a 档另记 density、area_cap_fraction、kind、params、SAM 2 的 CUDA 连通域算子是否可导入；b 档另记 prompt_file 及其 sha256、prompt_rule、n_prompts、n_windows_encoded；SAM 3 另记 phrase_index、phrases、confidence_threshold。
  done.json（评测完成）= predicted.json + thresholds（"fixed only" 或 "fixed and pool val_opt"）、val_thresholds、excluded、eval_seconds、summary（mAUPR、AUPR_any_lesion 等）、maps_dropped。
  metrics.json / metrics.npz 由 bench.eval.evaluate 写；evaluate 加了可选参数 val_thresholds（直接给 val_opt 阈值，指标名不变，结果多记 val_thresholds_given），默认行为不变。

五、运行方式（服务器；命令详见 17 第六节）
  启动器 bench/scripts/launch_e5_infer.py：按协议枚举；池运行 22 项在前；测试运行只在相应 selected 填好后列出（SAM / SAM 2 只跑选中密度并遵守预算规则；SAM 3 三个序号加一个以三个序号目录 done.json 为闸门的拼装项）；b 档始终；同信息对照在 runs/BS_m2mrf_<库>_seed0/prob_test、runs/NN_default_<库>_fold0/prob_test 存在时加入；done.json 齐的和 console.log 显示仍在跑的跳过；排序先池后测试、画布大的先；--submit 时先在本进程生成缺的提示文件；每项一条 shell（== start / == exit 行，日志在该项主目录），SAM 3 用 retiseg-sam3，其余 retiseg；复用 launch_b1.run_queue；plan 带 limit，冒烟目录对全量队列不算完成；--submit 只检查并生成本次计划用到的 prepared 库和提示文件（Item 记 split、variant、needs_prompts；absent_sets、missing_prompt_files(frozen, items)），只有 IDRiD、DDR 的机器也能做 --pool-only 冒烟（2026-10-12 评审修复 2）；测试项以本来源池目录为闸门（amg 九个、prompted 各 k、SAM 3 措辞各自序号、测试拼装项另加池拼装项），同信息对照无闸门；池拼装项标 prerequisite，--test-only 保留；gate_for(item, producers, limit) 在没有谁会写该目录、或写它的项自队列启动后已完成一轮却没写出 done.json 时返回 never（producers_of 在排队前记下每个生产者日志里已完成的轮数，旧失败不算）（2026-10-12 评审修复 3）；Item.owns_drop 为 False 的项（SAM 3 措辞项）不接 --drop-maps，措辞项 argv 带 --no-assemble（评审修复 4）。
  server_run.sh 阶段：RETISEG_GPUS="2 3" bash bench/scripts/server_run.sh e5-infer [--pool-only|--test-only] [--only ...] [--drop-maps FGADR,Retinal-Lesions] [--limit N]。
  单项命令：python -m bench.e5.amg --model SAM --density 64 --set DDR --split val；python -m bench.e5.prompted --model "SAM 2" --kind boxes --set IDRiD --split test；python -m bench.e5.sam3_text --phrase 0 --set DDR --split val / --select / --assemble；python -m bench.e5.prompts --set IDRiD --split test；python -m bench.e5.same_info --model M2MRF --tokens ddr seed0 --pred-dir runs/BS_m2mrf_ddr_seed0/prob_test --set DDR。
  顺序：环境与权重 → 冒烟 --pool-only --limit 2 → 池运行 → 两处选择写回 e5_frozen.yaml 并提交 → 测试集 → 回传 runs/E5 的 json。

九、与 15 原文的差异和已知限制（都已写进相应文件头或 00）
