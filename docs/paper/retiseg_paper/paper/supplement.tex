\section{Supplementary Notes}

\subsection*{Supplementary Note 1: the registered model variants}
One entry per registered variant: family, tier (1, main comparisons; 2, later rounds; 3, paper audit only), reproducibility level (R0 no code; R1 model definition only; R2 inference code and weights; R3 training code; R4 training code, weights, splits and environment), track (A, released weights; B, unified retraining of the official code; C, re-implementation from the paper), the code used, and what was changed or found when the code was run. The registry is \texttt{bench/configs/models.yaml} in the code repository; the notes are those recorded at the code audit and updated as runs completed.

\section*{Supplementary Data}
\noindent The following files will be released with the code.
\begin{itemize}[leftmargin=*,itemsep=2pt]
\item \textbf{Supplementary Data 1.} Split lists of every source (\path{bench/data/splits/} in the code repository): the image identifiers of each train, validation and test split, the subset lists of the training-amount experiment, and the near-duplicate exclusions.
\item \textbf{Supplementary Data 2.} The literature extraction (\path{literature/meta/reported_results.tsv}): one row per paper, baseline, dataset, class and metric, with the stated provenance of every number, and the per-paper audit (\path{paper_audit.tsv}).
\item \textbf{Supplementary Data 3.} The results table behind every figure and table of the main text and of this document (\path{docs/paper/retiseg_paper/paper/data/results.csv}), with the recipe, environment and deviation record of every run; its experiment column uses the identifiers of Supplementary Table~18.
\item \textbf{Supplementary Data 4.} Probability maps of every main-table model on every test set whose licence allows derived data to be released (IDRiD, DDR, TJDR, MAPLES-DR, DiaRetDB1), as 16-bit images, so that any metric can be recomputed.
\end{itemize}
