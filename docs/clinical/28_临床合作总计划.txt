零、一句话
医生不从零勾画像素。我们把模型和数据集标注不一致的地方挑出来，请医生判断：这里到底有什么、是谁错了、为什么错、这个错误放到临床分级和转诊里有多大影响、怎样才能避免。同一套记录同时审查数据集、审查模型，并给出领域该往哪里走的证据。

一、目的与研究问题
  论文现在用像素 mAUPR 和病灶级精度、召回说话，已经知道的现象有：MA 的病灶级精度中位只有 0.29、小出血的召回 0.15（R7）；粗标注、区域共识和超广角上分数掉三分之一到一半（R4、R6）；DiaRetDB1 四名专家之间 MA 的一致性最低（M16a）；0–1 级与 2–4 级图像的分数差很多（M17a）。这些现象都还缺一个临床解释：低分里有多少是模型真的错了，有多少是标注漏了、画大了、类别约定不同，又有多少错误在临床上根本无关紧要。临床合作要回答的就是这一层。
  RQ1 归属：模型与标注的分歧中，模型错、标注错、两者都错、定义本身有歧义、照片不足以判断，各占多少；按病灶类别、大小、数据集、DR 分级分开看。
  RQ2 机制：模型的误检来自哪些"拟态"（血管交叉、视盘旁、反光、玻璃膜疣、色素、伪影），漏检发生在哪些情形（小、淡、拥挤、局部质量差、周边）；标注的错误是漏标、错类、轮廓过大（一圈套住几个病灶和背景）、轮廓不全，还是数据集自己的约定。
  RQ3 临床后果：每个错误若被用于分级，会不会改变 ICDR 分级、DME 判断或转诊；有多少错误本身就是"决定性"的（例如唯一的 MA 决定 0 级还是 1 级，黄斑中心的渗出决定是否累及中心的 DME）。整图层面：只看模型的病灶图，分级与转诊会不会和医生一致。
  RQ4 指标与临床的距离：像素和病灶级指标惩罚的错误，和医生认为重要的错误是否是同一批；按医生裁定校正标注之后，模型的"真实"病灶级精度和召回是多少。
  RQ5 方向：医生认为什么最能减少这类错误（更清楚的病灶定义、专科医生重标、更高分辨率、质控、更多病灶类别、更多上下文、OCT 等其他模态），基准应补哪些类别，像素级病灶图在哪些临床场景有用。
  这次不做：从零勾画像素真值（代价高，DiaRetDB1 已经显示多名专家各画一遍的差异很大，而且公开库已有像素标注）；为临床合作重新训练模型；收集新的外部数据集（26 T6，仍是未来工作）。

三、被审查的模型与数据
  1. 模型：RetiSeg-Ref（两成员集成：RETFound + UPerNet 与 SAMed，IDRiD + DDR + TJDR_std 合并训练，阈值是集成在 DDR 验证划分上的 val-opt；14 备注 58，bench/reference.py）。理由：它是论文发布的参考模型，代表本文发现配出的最好做法；它犯的错比某个旧模型的错更能说明"当前模型的通用问题"；医生看到的轮廓与用户下载后得到的一致。
     在 IDRiD、DDR、TJDR_std 的官方测试划分上它是源内测试（同一标注风格），在 TJDR_uwf、MAPLES-DR 上是外部测试；两类分开报告，正好对应"同风格标注下还剩什么错"与"换了相机、视野和标注者以后多出什么错"。
     备选（第十二节 D2）：SAMed 单模型（DDR 最好的单模型）或 E-top3 集成。不建议：前者只代表一个结构，后者不是发布物。
  2. 通用性（模型共识度）：每个分歧区域都附上主表 18 个登记模型（DDR 训练、种子 0、各自验证阈值；集成成员表 bench/scripts/ensemble.py MEMBERS）里有几个在同一区域给出阳性（zoo_frac）。几乎所有模型都标、数据集没标的误检，是漏标的候选；没有一个模型找到的漏检，要么是真难的病灶，要么是可疑的标注。这是"标注不行还是模型不对"的第二条独立证据，分析时与医生的裁定交叉（第七节 S2）。医生看不到这个数。

四、审查单位：分歧区域
  定义（与 clinical/scripts/mine_discrepancies.py 一致）：对每张图、每个类别 c，有效区 = 视野去掉该类的忽略区；G = 有效区内的标注，P = 有效区内概率 ≥ 模型阈值；把 G ∪ P 按八连通分成连通区域（M11 的连通规则），每个区域是一个审查单位，类型按下面的规则定：
    FN 漏检      区域里只有标注、没有预测
    FP 误检      区域里只有预测、没有标注
    extent 范围  两者都有，区域内 IoU < 0.5（含只相邻不重叠）
    agree 一致   两者都有，IoU ≥ 0.5（对照）
    另记子类型 confusion：误检区域大部分（≥30%）落在另一类的标注上，或漏检区域大部分被另一类的预测覆盖（例如标注为 HE、模型判为 MA）。
  每个区域记：外接框、质心、两者面积与交集、IoU、等效直径与视野直径之比和大小档（protocol.yaml 冻结的 0.005、0.011）、区域内该类的最大与平均概率、与其他类标注和预测的重叠、到视野中心的相对距离、图像分级、模型共识度（第三节第 2 条）。每张图另记各类各类型的区域数（抽样权重的分母）。
  为什么用区域：孤立的区域与 M11 的病灶级单元一致，指标与裁定可以对上；一个区域是医生一眼能判断的范围；一处预测把几个标注病灶连起来时，它们合成一个区域，医生也是这样看的。
  一致区域作对照：盲读时医生分不出对照和分歧，于是可以估计"凡是被圈出来的都说有问题"这种倾向，也给"两者都错"（模型和标注一起把反光当渗出）留出位置。

五、抽样设计
  1. 两阶段：先按层抽图（层 = 数据集 × 分级档），再在图内抽区域。两臂：
     代表臂（概率样本）：每张图抽 1 个漏检、1 个误检、1 个对照；先在该图有这类区域的类别中等概率选一类，再在该类中等概率选一个区域。入样概率 π = (n_层 / N_层) × (1 / 可选类别数) × (1 / 该类该型区域数)，设计权重 1/π。论文里的比例（例如"误检中有多少是漏标"）只用这一臂加权估计。
     富集臂（目的样本）：在已抽中的图里，按条件随机抽：高置信误检（概率 ≥ 0.9）、确定的漏检（最大概率 ≤ 0.1 且中、大病灶）、类别混淆、范围分歧（HE、EX、SE）、模型共识误检（zoo_frac ≥ 0.8）。不加权，用于机制、案例图和讨论。
  2. 同一张图内各区域的裁剪窗互不重叠：揭示某个区域的轮廓时，画面里不会出现另一个待读区域的答案。重叠的抽取作废重抽，次数记录在 selection.json（有重抽的图，权重标为近似）。
  3. 随机数用 PCG64，种子写在设计文件里；设计文件（clinical/designs/pilot01.yaml）在打包前提交，抽样结果 selection.json 由服务器生成后回传、提交到 clinical/selections/。读过以后不改设计，要改就写新文件（pilot02.yaml）。
  4. 试点配额（pilot01.yaml）：
       DDR 0–1 级 4 张（这一层只要求有一个分歧：轻度图上一个误检就能把 0 级变成 1 级）
       DDR 2–4 级 8 张、IDRiD 4 张、TJDR_std 3 张、TJDR_uwf 3 张、MAPLES-DR 2 张，合计 24 张
       代表臂每张约 3 个，约 70 个；富集臂 28 个（高置信误检 8、确定漏检 8、混淆 4、范围 4、共识误检 4）
       合计约 100 个区域，24 张图。
     对"约 100 个标注"的理解：100 个区域（约 24 张图）。如果斯坦福说的是 100 张图，时间约为四倍，要先和对方确认（L2）。
  5. 主阶段规模（试点后按实测时间定，第十二节 D6）。以 4 类 × 漏检/误检 8 个格子、每格比例 p = 0.3、设计效应 1.3、15% 对照、每个区域由三名医生中的两名阅读估算：
       S  约 300 个区域（每格约 32）  每格 95% 区间半宽约 0.18  每位医生约 4.5 小时
       M  约 460 个区域（每格约 50）  约 0.145                 约 7 小时
       L  约 690 个区域（每格约 75）  约 0.12                  约 10.5 小时
     合并类别后的总比例要窄得多（M 档下误检合计约 200 个，半宽约 0.07）。时间按每个区域 1 分钟、每张图 1.5 分钟、每图约 4 个区域估计，试点会给出真实数。

六、阅读流程与工具
  1. 每张图的顺序（工具强制）：
     a 整图评估：只有原图，没有任何轮廓。图像质量与问题、ICDR 分级、DME（ICDR 分级的照片替代：硬性渗出相对黄斑中心的位置）、其他所见（IRMA、NV、静脉串珠、视网膜前或玻璃体积血、激光斑、玻璃膜疣等）、点出黄斑中心与视盘中心（可跳过）。
     b 每个区域 A 步（盲）：只显示一个中性虚线圆。医生回答"圈里主要是什么"（MA、出血、硬渗、棉绒斑、IRMA、NV、视网膜前出血、玻璃膜疣、激光斑、色素、血管或交叉、视盘、反光、正常背景、三类伪影、无法判断）、把握程度、圈里是否不止一个病灶。医生不知道这个圈是漏检、误检还是对照，也不知道数据集名称。
     c 揭示：A 步的回答从此锁定（工具记录揭示时刻）。只在这个区域的裁剪窗内画出数据集标注（实线）和模型（虚线），四类各一个颜色，可开关热图。
     d 每个区域 B 步：主因（无实质差异 / 标注错模型对 / 模型错标注对 / 都错 / 定义依赖 / 照片无法判断）；标注错在哪（漏标、无病灶却标了、错类、轮廓过大、轮廓不全、错位、数据集约定）；模型错在哪（血管、视盘、反光、亮病灶、暗点、伪影、错类、漏小病灶、漏于质量差处、漏于拥挤处、范围过小、范围过大或合并、周边畸变）；对人类阅片者的难度；临床影响 0–3；是否决定性；影响哪些决定；什么能减少这类错误（可选）；示教病例标记；自由文本"这里哪里出了问题"。
     e 整图小结：全图轮廓都显示。只看模型的病灶图会得到怎样的分级（相同 / 低一级 / 低两级以上 / 高一级 / 高两级以上）、转诊决定是否相同（会漏转 / 会多转）、数据集标注与模型病灶图的整体质量；数据集自带分级时显示并问是否同意；本图最重要的临床问题（可选）。
     全部图读完后有一页 5 分钟的结束问卷：各类漏检与误报在筛查里的代价、病灶图的用处、基准该补的类别、缺失或不清楚的选项、领域优先方向、对工具的意见。
  2. 临床影响量表（30 有每档的例子）：
       0 无       不影响任何临床决定
       1 轻微     只改变病灶数量或范围；分级、DME、转诊都不变
       2 中等     改变 DR 分级或 DME 类别，不改变转诊
       3 重大     改变转诊决定或其紧急程度
     另问"决定性"：这一个病灶本身就决定一个分级门槛（唯一的 MA、黄斑中心的渗出、新生血管）。量表回答的是"这个错误有多大影响"，决定性回答的是"这个病灶是不是关键的那一个"，两者分开记，分析时交叉。
  3. 偏倚控制：图像顺序与图内区域顺序按读者编号打乱（工具内置，可复现）；A 先于 B 且揭示后锁定，主要终点用 A；对照区域混在其中；轮廓只在当前区域窗口内显示、同图窗口不重叠；读者之间不讨论，直到试点讨论会；医生看不到模型概率数字、共识度和数据集名称（超广角从画面上能认出来，接受）。
  4. 工具（clinical/reader_tool/index.html，单个 HTML 文件，不联网、不安装）：数据包目录里双击 index.html 即可；Chrome、Edge、Firefox 都可以。原图按原分辨率显示，滚轮缩放、拖动平移、小地图；亮度、对比度、无红光（绿通道）视图；数据集轮廓、模型轮廓、热图、四类各自开关；键盘：1–9 选项、回车下一步、F/Z/G/D/M/H/K 快捷键。答案每次改动自动存到本机浏览器，结束时"Export results"导出 JSON 发给我们；Chrome、Edge 还可以绑定一个文件持续写入；换电脑时导入上次的文件继续。记录每一步的有效阅读时间（窗口不在前台或 90 秒无操作不计）、揭示时刻、读者编号、工具和问卷版本。
     问卷的唯一来源是 clinical/schema/review_schema_v1.json（字段代码、选项、显示条件），打包时写进数据包，工具按它生成表单，分析脚本按它解释代码；改问卷只改这个文件，代码不重用。
  5. 数据包（build_pack.py 写出）：index.html、pack.js / pack.json（问卷、每张图的轮廓多边形、区域的圆和窗口）、images/（原图）、heat/（各类热图，降采样）、READ_ME_FIRST.txt、SHA256SUMS.txt。包里没有数据集名称、图像原编号、区域类型、概率与权重；这些都在 selection.json（钥匙），留在我们这边。试点包约 24 张图，估计 60–150 MB（超广角图较大）。
  6. 时间估计：每个区域 A + B 约 45–60 秒，每张图的整图评估与小结约 1.5 分钟；试点每位医生约 2–2.5 小时（含 10 分钟练习与 5 分钟问卷），建议分两次读。

七、分析计划（clinical/scripts/analyze_reviews.py；读者导出 + selection.json → regions_long.csv、images_long.csv、report.md。脚本现在给出 P1–P3、S1、S4、S6 与试点检查；S2、S3、S5 的计算在试点数据到手后补，规则以本节为准）
  1. 主要终点（预先写定）：
     P1 盲读归属：代表臂里，误检区域中医生在 A 步认出的正是该类病灶的加权比例（= 标注漏标），漏检区域中医生认出该类病灶的比例（= 模型真漏）；按类别报告，95% 区间按图像 bootstrap（2000 次，种子 0）。映射规则：A 步答案落在该类 → 对应方对；落在正常结构或伪影 → 另一方对；落在别的病灶类 → 错类；无法判断 → 未定。
     P2 揭示后主因：B 步主因的加权分布，按类别 × 类型。
     P3 临床后果：影响 ≥ 2（改变分级或 DME）与 = 3（改变转诊）的比例，决定性病灶的比例；按类别、类型、分级档。
  2. 次要：
     S1 机制与标注问题的频数（多选），按类别 × 类型；富集臂单独列，作为案例来源。
     S2 共识度与归属：标注错的概率对 zoo_frac 的 logistic 回归（按图聚类的稳健标准误）；回答"所有模型都不同意标注时，标注有多大概率真的错了"。
     S3 校正后的病灶级精度与召回：用代表臂的加权比例把"漏标的误检"从误检里移出、把"假标注的漏检"从漏检里移出，得到校正后的 MA、HE、EX、SE 病灶级精度和召回，与 R7 的原数并列。
     S4 一致性：各字段读者间的完全一致率、两两 Cohen's κ、Fleiss' κ、Gwet's AC1（类别不平衡时比 κ 稳），有序字段（影响、难度、分级）报二次加权 κ。一致性本身也是结果：MA 与点状出血、棉绒斑与反光的不一致，说明定义需要收紧。
     S5 整图：医生分级与数据集分级的 κ；模型病灶图推出的分级、转诊与医生一致的比例（这是 N5 端点的人参照）。
     S6 改进方向的票数；自由文本由两人独立做主题编码，分歧讨论定稿。
  3. 合并规则：主要终点每位读者分别报告，再报多数票（三人）或一致项（两人）；平票的项在试点讨论会上看图定，记录为裁定，不覆盖原始回答。
  4. 图表草案：a 归属堆叠条（类别 × 误检 / 漏检，A 步与 B 步并排）；b 机制与标注问题的点阵图；c 临床影响阶梯（0–3）与决定性比例；d 共识度对标注错概率；e 校正前后的病灶级精度与召回；补充表：各字段一致性、试点完成度与时间。

八、试点
  1. 目的：可行性（每个区域实际用时）、问卷完整性（"其他"与"无法判断"的比例、自由文本里出现的缺失类目）、读者一致性、工具问题、抽样配额是否合理（例如某类误检几乎都是视野边缘伪影，主阶段就要按位置分层或剔除）。
  2. 通过标准（预先写定）：每个区域有效时间中位 ≤ 60 秒；A 步"其他病灶"与"无法判断"合计 < 15%；B 步主因的 κ ≥ 0.4 或 AC1 ≥ 0.5；每位读者完成 ≥ 90%；没有阻断阅读的工具问题。未达标的项在主阶段前修改并在 00 记录。
  3. 试点后允许改：选项措辞、增加选项（用新代码，旧代码不改义）、删并很少用的选项、配额、窗口大小、工具。不改：A 先于 B、揭示后锁定、对照混入、权重定义、主要终点。
  4. 试点数据能否进主分析：问卷只做措辞级修改时进（版本号 1.0.x）；主问题的选项结构有改动时，试点只作训练和设计依据（版本号 1.1）。
  5. 试点后开一次 30–45 分钟的讨论会：看分歧最大的 10 个区域、确定类目修改、确定主阶段规模与读者分配。

十一、风险与对策
  医生时间比预期少：代表臂优先于富集臂；主阶段每个区域由两人读（三人轮换），而不是三人全读；整图小结可以只在每图第一位读者做。
  许可不允许给对方看某些库：只用 IDRiD 与允许的库；或改为视频会议里由我们操作工具、医生口述（工具不变，读者编号照记）。
  "圈出来的就是有问题"的暗示：对照区域混入，A 步不告诉类型；分析里先看对照被判为有问题的比例。
  揭示后的锚定：A 锁定；主要终点只用 A；B 用于机制。
  阈值决定了哪些算分歧：用模型发布的阈值（DDR 验证选出）；另在固定 0.5 下重挖一遍，只报告分歧数量的变化，不加读。
  数据集风格泄露（超广角一眼可见）：接受，按数据集分层报告。
  问卷类目不全：每页有自由文本；试点后修订（第八节第 3 条）。
  疲劳与顺序效应：分次阅读；顺序按读者打乱；记录有效时间，分析时检查前后半程的差异。
  浏览器存储丢失：自动保存 + 每次结束导出 + 可绑定文件；导入可在另一台电脑继续。
  仓库是公开的：数据包、读者回答、分析输出都不进 git（.gitignore：clinical/work、clinical/packs、clinical/reviews）；设计与抽样名单进 git，作预登记。论文发表前，试点数字写进 00、14 时注意公开性。
